# The Barons of Orzelbirg

The players' podcast for the Irregulars campaign.

**Subscribe:** add `https://alevensailor.github.io/orzelbirg-podcast/feed.xml` to your podcast app ("add by URL"), or listen at https://alevensailor.github.io/orzelbirg-podcast/

To add an episode: put the MP3 (64 kbps mono) in `episodes/`, give it a row in `tools/episodes.json`, and run `python3 tools/build_feed.py` from the repo root.
